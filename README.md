# Coastal Climate Perceptions, Cooperation and Preferences

Replication code for the Climate Risk & Cooperation project.  
Analysis of experimental survey data on climate risk perceptions and cooperative behaviour in fisheries-dependent communities (N = 1,200+).

## Data

The raw data file (`cleaned_06062024_non_pii.xlsx`) is **not tracked by this repository** (see `.gitignore`). It contains non-PII survey data collected across coastal communities in Kerala and Tamil Nadu.


## Analysis Overview

| Section | Content |
|---------|---------|
| 1 | Variable construction (treatment, covariates, demographics) |
| 2 | Outcome variables (PGG contributions, social norms, psych distance) |
| 3 | Descriptive statistics and balance checks |
| 4 | Main regression analyses (OLS, heterogeneity by coastal proximity, norms outcomes) |
| 5 | Robustness checks (alternative thresholds, placebo tests) |
| 6 | Additional analyses (climate risk perceptions, life preferences) |
| 7 | Visualizations (KDE plots, box plots, margins plots) |

## Key Finding

Shared coastal exposure is a significant driver of public goods contributions. Treatment heterogeneity analysis shows differential effects by proximity to the coastline.
